# 🤝 Contributing to Sumahim SysTrack-Lite

Thank you for showing interest in contributing to **Sumahim SysTrack-Lite**! 🎉

This project is aimed at building a lightweight, bash-based monitoring solution for Linux users who care about security, transparency, and simplicity.

We welcome contributions of all types — from beginners to experts.

---

## 🛠 How to Contribute

1. **Fork the repository**
2. **Create a new branch**
   ```bash
   git checkout -b feature/your-feature-name
   ```
3. **Make your changes**
4. **Commit your work**
   ```bash
   git commit -m "Add: your meaningful commit message"
   ```
5. **Push to your fork**
   ```bash
   git push origin feature/your-feature-name
   ```
6. **Submit a Pull Request**

---

## 🌱 Beginner-Friendly Ways to Contribute

- Improve error handling in `systrack.sh`
- Add new monitoring modules (e.g., RAM usage, network connections)
- Refactor code for readability
- Translate `README.md` into other languages
- Write unit tests or shellcheck validation
- Fix typos or formatting in documentation

Look for issues labeled **`good first issue`** or **`help wanted`** to get started quickly.

---

## 🧪 Code Guidelines

- Write clear, POSIX-compliant Bash when possible
- Comment your code if it's non-obvious
- Follow naming conventions: `kebab-case` for scripts, `snake_case` for variables
- Use double quotes around variables (`"$var"`) to avoid word splitting
